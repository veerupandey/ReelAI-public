# Ad Copywriting — Review Checklist

Run before presenting the plan to the user. Any failure is a mandatory fix.

## Fact grounding
- [ ] Every ingredient mentioned appears in `facts[]`
- [ ] Every benefit claim traces to a `facts[]` entry
- [ ] No certification claims unless in `facts[]` (clinically proven, dermatologist tested, hypoallergenic)
- [ ] No invented percentages or statistics

## Pacing
- [ ] Each scene word count ≤ `floor(targetDurationSec × 2.5)`
- [ ] Total estimated voiceover (words ÷ 2.5) within ±15% of `durationSec`
- [ ] Hook (scene 1) is ≤8 words — pattern interrupt, not a sentence

## Structure
- [ ] Scene count matches `sceneCount` exactly
- [ ] Brand name in final scene
- [ ] No filler words ("beautiful", "amazing", "incredible") without a grounded claim

## Memory compliance
- [ ] No entry in `LEARNED RULES` is violated
- [ ] If a past mistake was "invented walnut" → walnut does not appear

## Style
| Style | Check |
|---|---|
| `luxe_minimalist` | Short sentences, understated, no superlatives |
| `earthy_organic` | Sensory textures, natural metaphors |
| `high_energy` | Action verbs, movement in language |
| `ugc_style` | First-person opener, honest, relatable |
