# Creative Review — Manual Checklist

Use this when the Gemini review call fails or user wants to manually review before export.

## Factual accuracy
- [ ] Hook voiceover contains no invented ingredients
- [ ] Ingredients scene only names items from `facts[]`
- [ ] No certification claims (clinically proven, dermatologist tested) unless in `facts[]`
- [ ] No statistics or percentages unless in `facts[]`

## Hook (scene 1)
- [ ] First line ≤8 words
- [ ] Creates a pattern interrupt — question, bold claim, or visual intrigue
- [ ] Does not start with "Introducing" or the product name

## Narrative arc
- [ ] Hook → proof/ritual → ingredients → result/emotion → CTA
- [ ] Each scene does a distinct job (no two scenes say the same thing)
- [ ] Emotional peak is in the result or ritual scene, not the CTA

## Platform fit

**instagram_reels**
- [ ] Pacing allows a breath between scenes (not rushed)
- [ ] Aesthetic is premium and cohesive
- [ ] Captions are optional — content works without sound

**tiktok**
- [ ] Hook lands in first 1.5 seconds
- [ ] Proof point is in scene 2 (not scene 4)
- [ ] Creator-native tone (not overly polished)

**youtube_shorts**
- [ ] Voiceover is clear and slightly explanatory
- [ ] Benefits stated early (within first 5 seconds)

## CTA
- [ ] Final scene states the brand name
- [ ] Has an implicit or explicit call to action (try it, shop now, link in bio)
- [ ] CTA matches platform norms (TikTok: "link in bio"; Reels: "shop now"; Shorts: "check the description")

## Video technical
- [ ] No black frames between clips
- [ ] Audio does not cut off before video ends
- [ ] Captions are readable (not obscured by product image)
- [ ] Video is 9:16 vertical format
